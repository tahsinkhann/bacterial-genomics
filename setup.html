Docker

In this training, we will be using Docker as container where we will install different bioinformatics tools and run it. Containerization is a system that allows multiple isolated operating systems to run inside a larger, host system. Docker is one such container which can be used within any operating sustems such as Windows, Linux or Mac OS. Docker is an open platform for developers to build and ship applications, whether on laptops, servers in a data center, or the cloud. It is a (relatively?) painless way for you to install and try out Bioinformatics software.

You can think of it as an isolated environment inside your exising operating system where you can install and run software without messing with the main OS.

Note that we use tabsets to provide instructions for Windows, Linux and `Mac OS. Follow the instructions based on your laptop’s operating system.

Setting up required softwares

Here will discuss how to setup Docker Desktop and with it to build images for the required tools. We will download sequence datasets and databases required in this training.

  • Windows
  • Linux
  • Mac OS

Part 1: Training folder setup

Step 1: Enter your C:\ drive
Step 2: Create a new folder called genomics (all lowercase letters)

NoteNOTE

You will need about 50 GB free space. If your C drive does not have enough space, you may use a different drive (e.g., D:\) , but make sure you substitute this into all commands accordingly.

Part 2: Download the training materials

Step 1: Go to the drive link

Step 2: Download the materials.zip file

Step 3: When the file has been downloaded, unzip it

Step 4: Enter to the materials folder until you see 4 sub-folders:

  • dockerfile
  • kraken2db
  • raw_data
  • run_output

Step 5: Copy these 4 folders to the genomics folder you created in your C:\ drive in part 1.

Here is the drive link to download materials.zip file

Part 3: Install Docker Desktop

Step 1: Go to the docker website and click on Download Docker Desktop and select Download for Windows - AMD64. Click here to visit Docker Website.

NoteNOTE

If you have ARM system then download that instead.

Step 2: Go to your Downloads folder and click on the file that was just downloaded. Follow the instruction to install Docker Desktop and wait for the installation process to finish.

WarningWARNING

During installation you may be asked to install WSL. If so, please install it.

Part 4: Setup Docker Image

Step 1: Once installation is complete, go to start menu and click the Docker Desktop.

Step 2: First time you start Docker Desktop you will be asked to Login/Sign up. You may ignore it by clicking on skip.

Step 3: Open your Start Menu and type Command Prompt in search icon.

Step 4: Open Command Prompt

Step 5: In the black window, type

cd C:\genomics
NoteIMPORTANT

If you used adifferent drive in Part 1, replace C:\ with that drive’s name in the command above.

Step 6: Press ENTER

Step 7: Type dir and press ENTER

Step 8: In the window, you will see the names of the 4 folders:

  • dockerfile
  • kraken2db
  • raw_data
  • run_output
WarningWARNING

Before going further, ensure that Step 8 was successfully done.

Step 9: Now type the following and press ENTER

docker build -t wgs dockerfile

Step 10: Wait for the installation to complete.

NoteNOTE

This may take a very long time (~1 hour) depending on your internet speed. Make sure your internet is working properly before you run the command above.

Step 11: Once installation is complete, type

docker run --rm -it -v "C:\genomics":/genomics wgs /bin/bash

Step 12: Press ENTER

Step 13: Type the following and press ENTER.

check_files_script.sh

Step 14: If setup was done correctly, you will get a confirmation message, otherwise read all the instructions carefully and repeat the steps.

Step 13: Type the following in your terminal

fastqc --help

If you see details of the FastQC tools, that means your Docker installation and Database setup are complete! Hurray!!!

Part 3: Install Docker Desktop

Step 1: Write the following code in your terminal. It will ask you to type your laptop password. Type your password and press ENTER.

sudo apt install gnome-terminal

Step 2: Now install the apt repository:

# Add Docker's official GPG key:
sudo apt-get update
sudo apt-get install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the repository to Apt sources:
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update

Step 3: Download the DEB file

curl -o ./docker-desktop-amd64.deb https://desktop.docker.com/linux/main/amd64/docker-desktop-amd64.deb

Step 4: Install Docker Desktop

sudo apt-get update
sudo apt-get install ./docker-desktop-amd64.deb
TipOPTIONAL

Remove the docker-desktop-amd64.deb file

rm docker-desktop-amd64.deb

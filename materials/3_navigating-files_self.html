Navigating Files

Overview

In this lesson, we will create a personal working directory, and copy the Day 1 training files into that directory.

Learning objectives

By the end of this lesson, you should be able to:

  • check your current location using pwd
  • list files using ls
  • create a personal working directory
  • copy Day 1 files using the in-house script

Step 1: Open Ubuntu

  1. Click the Start Menu.
  2. Search for Ubuntu.
  3. Click Ubuntu.

Running as administrator is not required.

This is how you will open an Ubuntu terminal inside Windows.

Step 2: The Bash Terminal

This is called the Bash terminal.

You will see a prompt similar to:

username@computer-name:~$

The tilde character (~) represents your home directory.

If you think of your computer as a house, the home directory is like entering through the front door.

Step 3: Open Linux Files in File Explorer

Open a File Explorer window.

  1. Open File Explorer.
  2. In the left-side panel, locate Linux (penguin icon).
  3. Click Linux.

Step 4: Open Ubuntu

Double-click on Ubuntu.

Step 5: Open Home

Double-click on home.

Step 6: Open Your User Folder

Double-click on the folder that matches the username you entered in Step 06.

Step 16: View the Home Directory

You are now viewing the same home directory that is shown in the Ubuntu terminal, but through File Explorer.

Step 17: Create a New Folder

Return to the Ubuntu terminal.

Type:

mkdir test

and press ENTER.

Step 18: Refresh File Explorer

Nothing may appear immediately in File Explorer.

In WSL, you often need to refresh the window before changes become visible.

Click the Refresh button near the top of the File Explorer window.

Step 19: Verify the New Folder

After refreshing, you should now see the newly created test folder.

Create a directory with your name

Create a directory using your own name.

For example:

mkdir tanzim
TipTip

Use your own name or assigned participant name instead of tanzim.

For example:

mkdir tahsin
Go inside your directory

Move into the directory:

cd tanzim

Check your current location:

pwd

You may see something like:

/home/genomevm/tanzim

List the contents:

ls

After the command finishes, list the files:

ls

You should now see the training files in your directory.

Check copied files

Use:

ls -l

This shows the file names and file sizes in a readable format.

You may see files such as:

S1_R1.fastq.gz      S1_R2.fastq.gz
Basic navigation commands
Command Meaning
pwd Show current directory
ls List files and folders
mkdir tanzim Create a directory named tanzim
cd tanzim Move into the tanzim directory
cd .. Move one directory back
clear Clear the terminal screen

Practical exercise

Complete the following tasks:

  1. Connect to the server using ssh.
  2. Accept the fingerprint by typing yes.
  3. Enter your password.
  4. Check your current directory using pwd.
  5. Create a directory with your name.
  6. Move into your directory.
  7. Run copy_day1_files.
  8. Use ls to confirm that files were copied.
CautionExercise: server setup

Create your own working directory and copy the Day 1 files.

Replace tanzim with your own name:

mkdir tanzim
cd tanzim
copy_day1_files
ls
TipAnswer

A successful setup should look like this:

ssh genomevm@172.28.28.12

yes

# type password when prompted

pwd
ls
mkdir tanzim
cd tanzim
copy_day1_files
ls

After running ls, you should see the copied training files.

Common problems
Problem Possible reason Solution
Permission denied Wrong password Try again carefully
Password not showing Normal terminal behavior Type password and press Enter
ssh: command not found SSH is not installed or terminal issue Use another terminal or install SSH
copy_day1_files: command not found Script not available in PATH Ask instructor
Directory already exists You already created the folder Use cd folder_name or choose a different name

Key points

NoteImportant
  • Use ssh to connect to the training server.
  • Type yes if the fingerprint message appears.
  • Passwords are invisible while typing in the terminal.
  • Use pwd to check your location.
  • Use ls to list files.
  • Use mkdir to create your own working directory.
  • Run copy_day1_files to copy the Day 1 training data.

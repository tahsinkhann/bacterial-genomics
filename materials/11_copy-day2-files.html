Copy Day 2 Files

Overview

In the previous lessons, we completed analysis for sample S1.

For the next parts of the course, we will work with eight samples. Instead of manually copying each assembly and annotation file, we will use an in-house bash script called:

copy_day2_files

This script will copy:

  • filtered assembly files into the assemblies directory
  • annotation files into the annotation directory

Learning objectives

By the end of this lesson, you should be able to:

  • run an in-house bash script
  • copy prepared files for eight samples
  • check that assembly FASTA files are present
  • check that annotation GFF files are present
  • prepare input files for AMR, pangenome, and phylogenetic analysis

After running the script, the assemblies directory should contain filtered assembly FASTA files:

S4.gff

S6.gff

S8.gff
NoteImportant

The assembly files will be used for AMR, virulence factor, plasmid, and other genome-level analyses.

The GFF files will be used for pangenome analysis.

Check the script

First, check that the script is available:

ls

You should see:

copy_day2_files

If the script is not in your current directory, ask the instructor or check the course data folder.

Run the script

Run the in-house bash script:

copy_day2_files

Check assembly files

After the script finishes, check the assemblies directory:

ls assemblies

You should see:

Troubleshooting

Problem Possible reason Solution
Permission denied Script is not executable Run chmod +x copy_day2_files.sh
No such file or directory Script is not in current folder Check location using ls
Fewer than 8 FASTA files Copy failed or source files missing Re-run script or ask instructor
Fewer than 8 GFF files Copy failed or source files missing Re-run script or ask instructor
Wrong folder name Script expects specific directory names Check with instructor

Run the script and confirm that all eight samples were copied.

Expected result:

8 annotation GFF files

Key points

NoteImportant
  • copy_day2_files.sh is an in-house script for preparing Day 2 files.
  • It copies eight filtered assembly files into assemblies.
  • It copies eight annotation files into annotation.
  • These files are required for AMR, pangenome, and phylogenetic analysis.

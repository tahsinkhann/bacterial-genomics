Learnings from Day 1

Overview

This recap session will help you practise the complete Day 1 workflow using a new sample.

You will be given paired-end sequencing files:

S2_R1.fastq.gz
S2_R2.fastq.gz

Your task is to complete the analysis from raw reads to assembly quality control and complete the following table below using your QUAST and CheckM2 results.

Assembly Number of contigs Total length (>=0 bp) N50 L50 GC% Completeness Contamination
Original assembly
Filtered assembly
NoteTime

You will have 30 minutes to complete this exercise.

Learning objectives

By the end of this recap session, you should be able to:

  • create a clean project folder structure
  • copy Day 2 recap files
  • run FastQC on raw reads
  • trim reads using Trimmomatic
  • run FastQC on trimmed reads
  • assemble reads using SPAdes
  • assess assembly quality using QUAST
  • estimate completeness and contamination using CheckM2
  • filter contigs smaller than 500 bp using seqkit
  • compare original and filtered assembly quality

Input files

The input files for this recap are:

S2_R1.fastq.gz
S2_R2.fastq.gz

After copying the files, they should be located in:

raw_reads/S2_R1.fastq.gz
raw_reads/S2_R2.fastq.gz

Connect to the server

Open your terminal and type your server IP, for example:

ssh genomevm@172.28.28.12

Go to your directory

cd tanzim

Create a directory called recap

mkdir recap

Enter to recap directory

cd recap

Step 1: Create directories

Create the required directories:

mkdir -p raw_reads qc_reports trimmed_reads assemblies quast checkm2

Check the directories:

ls

You should see:

raw_reads
qc_reports
trimmed_reads
assemblies
quast
checkm2

Step 2: Copy files

Copy the recap data using the in-house script:

day1_recap

Check that the raw read files were copied:

ls raw_reads

You should see:

S2_R1.fastq.gz
S2_R2.fastq.gz
NoteCheckpoint

Before moving to the next step, make sure both raw read files are present inside raw_reads.

Step 3: FastQC on raw reads

Activate the QC environment:

conda activate qc

Run FastQC on the raw reads:

fastqc \
  -t 4 \
  -o qc_reports \
  raw_reads/S2_R1.fastq.gz \
  raw_reads/S2_R2.fastq.gz

Check the output:

ls qc_reports

You should see raw-read FastQC reports:

S2_R1_fastqc.html
S2_R1_fastqc.zip
S2_R2_fastqc.html
S2_R2_fastqc.zip

Step 4: Copy raw FastQC reports to your local computer

If you are working on the server, download the raw-read FastQC reports to your local computer.

From your local desktop terminal, run:

scp genomevm@172.28.28.12:~/YOUR_NAME/recap/qc_reports/S2_R1_fastqc.html .
scp genomevm@172.28.28.12:~/YOUR_NAME/recap/qc_reports/S2_R2_fastqc.html .

Replace YOUR_NAME with your working directory name.

Example:

scp genomevm@172.28.28.12:~/tanzim/recap/qc_reports/S2_R1_fastqc.html .
scp genomevm@172.28.28.12:~/tanzim/recap/qc_reports/S2_R2_fastqc.html .
WarningImportant

Run scp from your local computer terminal, not from inside the SSH session.

Step 5: Trim reads using Trimmomatic

Run Trimmomatic in paired-end mode:

trimmomatic PE \
  -threads 3 \
  raw_reads/S2_R1.fastq.gz \
  raw_reads/S2_R2.fastq.gz \
  trimmed_reads/S2_trim_R1.fastq.gz \
  trimmed_reads/S2_unpaired_R1.fastq.gz \
  trimmed_reads/S2_trim_R2.fastq.gz \
  trimmed_reads/S2_unpaired_R2.fastq.gz \
  SLIDINGWINDOW:4:20 \
  LEADING:3 \
  TRAILING:3 \
  HEADCROP:15 \
  MINLEN:40

Check the trimmed read files:

ls trimmed_reads

You should see:

S2_trim_R1.fastq.gz
S2_trim_R2.fastq.gz
S2_unpaired_R1.fastq.gz
S2_unpaired_R2.fastq.gz
NoteCheckpoint

For assembly, you will use the paired trimmed reads:

trimmed_reads/S2_trim_R1.fastq.gz
trimmed_reads/S2_trim_R2.fastq.gz

Step 6: FastQC on trimmed reads

Run FastQC on the trimmed paired reads:

fastqc \
  -t 3 \
  -o qc_reports \
  trimmed_reads/S2_trim_R1.fastq.gz \
  trimmed_reads/S2_trim_R2.fastq.gz

Check the output:

ls qc_reports

You should now see both raw and trimmed FastQC reports.

Step 6b: Copy trimmed FastQC reports to your local computer

From your local desktop terminal, run:

scp genomevm@172.28.28.12:~/YOUR_NAME/recap/qc_reports/*.html .

Example:

  • Windows/Linux OS
  • MacOS
scp -r genomevm@172.28.28.12:~/tanzim/recap/qc_reports/*.html .
scp -r genomevm@172.28.28.12:~/tanzim/recap/qc_reports/'*.html' .

After finishing QC and trimming, deactivate the QC environment:

conda deactivate

Step 7: Genome assembly using SPAdes

Activate the assembly environment:

conda activate assembly

Run SPAdes using the paired trimmed reads:

spades.py \
  -t 3 \
  -o assemblies/S2_assembly \
  -1 trimmed_reads/S2_trim_R1.fastq.gz \
  -2 trimmed_reads/S2_trim_R2.fastq.gz

After assembly finishes, copy the main contig file:

cp assemblies/S2_assembly/contigs.fasta assemblies/S2_contigs.fasta

Check that the assembly file exists:

ls assemblies

You should see:

S2_assembly
S2_contigs.fasta

Step 8: QUAST on original assembly

Run QUAST on the original assembly:

quast \
  -t 3 \
  -o quast/S2_original \
  assemblies/S2_contigs.fasta

View the report:

cat quast/S2_original/report.txt

Record the following values:

  • number of contigs
  • total length
  • N50
  • L50
  • GC%
NoteCheckpoint

Use the QUAST report to fill in the Original assembly row in the results table.

Step 9: CheckM2 on original assembly

Run CheckM2 on the original assembly:

checkm2 predict \
  -t 3 \
  -x .fasta \
  -i assemblies/S2_contigs.fasta \
  -o checkm2/S2_original

View the CheckM2 report:

cat checkm2/S2_original/quality_report.tsv

Record:

  • completeness
  • contamination

Step 10: Filter contigs smaller than 500 bp

Use seqkit to remove contigs smaller than 500 bp:

seqkit seq \
  -m 500 \
  assemblies/S2_contigs.fasta \
  > assemblies/S2_contigs_filtered.fasta

Check that the filtered file exists:

ls assemblies

You should see:

S2_contigs_filtered.fasta

Count contigs before and after filtering:

grep -c "^>" assemblies/S2_contigs.fasta
grep -c "^>" assemblies/S2_contigs_filtered.fasta

Step 11: QUAST and CheckM2 on filtered assembly

Run QUAST on the filtered assembly:

quast \
  -t 3 \
  -o quast/S2_filtered \
  assemblies/S2_contigs_filtered.fasta

View the filtered QUAST report:

cat quast/S2_filtered/report.txt

Run CheckM2 on the filtered assembly:

checkm2 predict \
  -t 3 \
  -x .fasta \
  -i assemblies/S2_contigs_filtered.fasta \
  -o checkm2/S2_filtered

View the filtered CheckM2 report:

cat checkm2/S2_filtered/quality_report.tsv

Results table

Fill in the table below using your QUAST and CheckM2 results.

Assembly Number of contigs Total length (>=0 bp) N50 L50 GC% Completeness Contamination
Original assembly
Filtered assembly

Key points

NoteImportant
  • This recap uses sample S2.
  • The workflow starts with raw reads and ends with assembly quality control.
  • FastQC checks read quality.
  • Trimmomatic trims low-quality reads.
  • SPAdes performs genome assembly.
  • QUAST reports assembly statistics.
  • CheckM2 estimates completeness and contamination.
  • seqkit filters out short contigs.
